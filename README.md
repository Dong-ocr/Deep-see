## 这是什么
DeepSeek 模型本身不支持多模态/视觉功能。这个 Codex skill 通过本地 OCR（EasyOCR）让 DeepSeek 也能看见截图里的文字。

## 安装
```bash
pip install easyocr
```

## 特点
- 纯本地运行，不上传任何图片
- 支持中文、英文识别
- 首次安装后离线可用

## 使用方式
在 Codex 里发截图/图片，然后问"什么内容"即可自动识别。
